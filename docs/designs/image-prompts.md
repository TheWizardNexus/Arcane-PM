# Arcane PM design prompts

These static designs were generated with the built-in image-generation tool. The approved Arcane PM brand board and application mockups provided the visual references. All task data and product interactions in the images are illustrative.

The compact desktop home supersedes the earlier long landing-page draft. The site uses separate focused pages, with matching light and dark themes and mobile layouts.

Final image references are listed in the [project README](../../README.md). This record preserves the authored prompts; it does not establish implemented capabilities or public API contracts.

## Final prompt set

README header

Use case: ads-marketing / product identity.
Create a polished wide README header banner for Arcane PM by TWiN, using the supplied approved logo and UI screenshot as style and identity references. The first reference is the product's own light/dark logo board; the second is its warm, welcoming task-team interface. This banner is a project documentation cover, not a whole webpage or screenshot. Aspect ratio 3:1, landscape, high resolution.

Composition: on the left 55 percent, generous clean warm ivory space holds the approved logo mark and large precise text "Arcane PM", with small "by TWiN" underneath. Below, one legible concise subtitle "A familiar face for every task." Use the exact new logo: softly rounded upright triangle, central four-point gold spark, open circular orbit and small dot near upper right. Use deep teal lines and muted gold spark directly on the surface; NO black badge and NO original Arcane parent logo. Elegant rounded adult sans serif, dark ink text, sophisticated rather than childish.
The right 45 percent is a welcoming editorial arrangement of three small overlapping task cards with the distinctive faces from the screenshot: curly dark-haired glasses research worker, copper-haired writing worker, and short dark-haired project guide. Preserve their illustrated appearance. Their cards sit along a gentle curved orbit/connecting line, with subtle document and conversation icons to suggest cooperation and context passing. Keep faces prominent, cards sparse and tasteful, without tiny illegible task copy. Do not depict actual staff names, live statuses, fake metrics, code or error messages.
The rightmost background transitions smoothly into deep desaturated blue-green, with a few very restrained gold/lavender orbit accents echoing both themes. Cards and faces remain clear against it. No giant starfield, busy sci-fi machinery, robot characters, device frame, neon glow, stock photo or 3D gloss. Use only the approved teal/ivory/gold palette with soft lavender accents.
There should be one logo lockup, one subtitle, and simple human-friendly teamwork imagery. No download badges, installation command, availability claims or website address. Keep useful content comfortably inset from edges, and maintain readability when rendered at GitHub README width.
