Make room for what matters now.

Arcane PM’s proposed organization separates archiving from removal. Each action should explain exactly what it affects, so a quieter workspace can still preserve useful context.

1

Archive inactive work

The intended archive takes work out of the active view while keeping its context available for a later return.

2

Choose removal deliberately

Removal has a specific target, such as an app-owned task record. Its scope should be visible before the action runs.

3

Keep original ownership clear

An Arcane PM reference and its original conversation or file are separate things. Any action on the original belongs to the connection that owns it.
