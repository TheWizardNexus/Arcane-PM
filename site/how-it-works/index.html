How it works · Planned workflow

Give each project a clear next step.

Arcane PM is being designed to bring projects, tasks, conversations, and working files into one understandable workspace. Start with the work that matters, then give each task the context it needs.

1

Find your project

Keep its purpose, working folder, conversations, and open tasks together. A familiar place to return makes it easier to pick up where you left off.

2

Prepare the next task

Gather the original sources, decisions, and files. Give a worker one clear assignment and explain what a useful result would look like.

3

Follow the work

See what is working, what needs your input, and what is ready next. Pass the current context forward when another worker takes over.
