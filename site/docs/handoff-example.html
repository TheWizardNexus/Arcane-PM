Synthetic example · prepared only

One handoff, with its full context.

A fictional research task prepares an event-page update. Every selected source is included below, complete and unchanged.

All names and source notes on this page are synthetic. This is an illustration of a proposed handoff record.

Assignment

Update the Open Observatory Night project’s event-page draft using the selected planning notes. Prepare the revised page for review. Publishing is outside this assignment.

Research task

Find practical arrival information.

→
Project update

Prepare the revised page draft.

Research and decisions

The notes agree that first-time visitors need arrival information before equipment details. Lead with the meeting place, accessible route, and what to bring. Retain the existing telescope description. Keep the start time unresolved until the coordinator confirms it.

Open questions: What start time has the coordinator approved? Who will review the revised page?

Selected original sources

Synthetic source A · visitor planning note

First-time visitors asked where to meet and whether the path has steps. Meet at the east courtyard. The paved route from the east gate has no steps. Bring a warm layer and a red-light torch if you have one.

Synthetic source B · project editor note

Keep the existing description of the two telescopes. Put arrival information before the equipment section. The event time is still waiting for the coordinator’s confirmation.

Synthetic source C · review scope

Prepare the revised event page as a draft. The coordinator will review the date, time, and arrival instructions before anything is published.

Destination and state

Destination: the project’s event-page update task.

Ready

The destination has not confirmed acceptance.

The original research task and its sources remain available. Only an actual destination confirmation changes delivery to accepted; this example performs no send.
