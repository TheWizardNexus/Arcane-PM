Docs / UI components
Interface design

Make ongoing work easy to recognize.

Familiar illustrated faces help identify tasks. Clear text explains each assignment and its actual state.

The application design brings together the shared Arcane theme, a project task view, local records, and saved task-worker faces. The browser PWA has a local setup and packaging workflow; the reusable npm API and exported component library remain separate work.

Focused places to work

Project and task views
Find assignments, then open a focused page for decisions, questions, and current work.
Source and handoff views
Read complete selected originals and review the prepared context and delivery state.
Archive and cleanup views
Retrieve archived records and separately review selected disposable material.

Keep controls close

Give each primary action one clear placement. Preserve working controls in the ordinary flow while background preparation continues. On mobile, use compact navigation and focused pages instead of compressing every desktop panel into one screen.

Appearance and accessibility

The public docs provide Light, Dark, and System appearance through the website’s shared controls. The application loads the installed SDK’s shared Arcane theme and theme bootstrap before its own styles.

Preserve keyboard operation, visible focus, readable labels, reduced-motion preferences, and room for growing content. Faces supplement status text and controls. These design descriptions do not define an exported application component library.
