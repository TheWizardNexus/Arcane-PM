Context handoffs · Planned workflow

Help the next worker pick up the thread.

A useful handoff brings together the purpose, current state, original sources, and next action. Arcane PM is being designed to keep that context with the project as work changes hands.

1

Explain where things stand

Record what was completed, what remains open, and the decisions that shaped the work. Keep the actual outcome separate from the next proposal.

2

Point to what matters

Include the files and original references needed for the next step, along with enough explanation to make each one useful.

3

Make the next action clear

Name the task, the expected result, and any decision still needed. Review the prepared handoff before sending work through a supported connection.

Project continuity across connections. Arcane PM is intended to retain its own project coordination when accounts change. Connected services still govern access to their conversations and actions; account switching does not automatically migrate chats.
